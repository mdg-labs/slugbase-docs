## What you'll learn

After reading this page, you will understand what SlugBase does on your own infrastructure, how it differs from SlugBase Cloud, and which guides to read next.

## What is SlugBase?

SlugBase is a bookmark manager with built-in URL shortening and keyboard-driven navigation. You save links in a **workspace**, assign short **slugs** to bookmarks, and jump to any destination from the address bar or command palette using **forwarding** (`/go/&lt;slug&gt;`).

On a CE instance you run the same product as SlugBase Cloud — one codebase in an **open-core** model: managed Cloud plus **source-available** Community Edition. Your data stays on infrastructure you control.

<Callout kind="info" title="Naming note">
Older docs and URLs may say **self-hosted** or use `/selfhosted/…` paths. SlugBase now calls this edition **Community Edition (CE)**. Doc paths use `/ce/…`; set `SLUGBASE_EDITION=ce` when configuring your deployment.
</Callout>

## How CE works

A SlugBase CE instance ships as a **combined container image** (API and web client on one port). You provide **PostgreSQL** for persistence and set environment variables for secrets, public URLs, and optional integrations.

Typical shape:

```text
Your reverse proxy (HTTPS)
        ↓
SlugBase container (port 3000)
        ↓
PostgreSQL
```

## Key concepts

### Workspace

A **workspace** is the top-level container for bookmarks, folders, tags, members, and settings. Every piece of data belongs to exactly one workspace. On CE, an **instance-wide administrator** creates workspaces and places members by invitation — public registration is off by default.

### Slug and forwarding

A **slug** is a short keyword on a bookmark (for example `docs`). When **forwarding** is enabled, signed-in workspace members can open `/go/&lt;slug&gt;` to jump to the bookmark's URL. Slugs are private to your workspace; they are not anonymous public short links.

### Folders and tags

**Folders** organize bookmarks into named containers. A bookmark can belong to multiple folders. **Tags** are flexible labels you can filter and search by — use both together when folders give structure and tags give cross-cutting themes.

## Community Edition vs SlugBase Cloud

| Topic | Community Edition | SlugBase Cloud |
|-------|-------------|----------------|
| Hosting | Your infrastructure | Managed by SlugBase |
| Billing | Not applicable — full entitlements on your instance | Free, Personal, and Team plans |
| User onboarding | Setup + invite by default | Public registration with email verification |
| SMTP, OIDC, and AI credentials | Configure via deployment environment variables | Operator-managed — not in workspace settings |
| Workspace settings UI | General settings and AI enable toggle only | General settings and AI enable toggle only |
| Marketing site | Separate deployment (not in the container image) | Operated separately |
