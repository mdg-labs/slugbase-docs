## What this page is for

**Bookmarks** (`/bookmarks`) is where you manage saved links: title, URL, optional **Slug** (for forwarding), **Folders**, and **Tags**. You can filter by folder and tag, search the library, switch **Card View** or **List View**, run bulk actions, and open **Import** or **Export** from the toolbar **More** menu.

<Callout kind="info">
  Self-hosted deployments use this page as-is. Cloud-only plan limits or upgrade messaging are not part of self-hosted core; see [Cloud introduction](/cloud/introduction) if you use the hosted product.
</Callout>

## Before you start

Create at least one folder or tag if you want those fields populated when editing bookmarks—they are optional. For browser shortcuts and `/go/<slug>`, see [Slugs overview](/selfhosted/slugs-overview) and [Browser setup](/selfhosted/browser-setup).

## How to create or edit a bookmark

<Steps>
  <Step title="Open Bookmarks" icon="bookmark" titleType="p">
    In the sidebar, choose **Bookmarks**.
  </Step>
  <Step title="Start the editor" icon="plus" titleType="p">
    Select **Create Bookmark**, or use **Edit Bookmark** from a row or card menu on an existing item.
  </Step>
  <Step title="Fill in the form" icon="file-text" titleType="p">
    Enter **Title** and **URL**. Optionally set **Slug**, assign **Folders** and **Tags**, and adjust **Enable Forwarding** if you use short links. Save with **Save**.
  </Step>
</Steps>

<Callout kind="tip">
  The empty state offers **Create your first bookmark** and **Import bookmarks** when you have no data yet.
</Callout>

## Filter, sort, and search on the page

Use the toolbar below the title:

- **Search** — placeholder **Search bookmarks, folders, tags...**; applies the query to the list when you submit.
- **Filter by Folder** / **Filter by Tag** — **All Folders** and **All Tags** clear the respective filter.
- **Sort By** — options include **Recently Added**, **Alphabetical**, **Most Used**, and **Recently Accessed**.
- **Per page** — page size (for example 50, 100, 200, 500).
- **More** — opens a menu with **Import**, **Export**, **Pinned** toggle, **View Mode** (**Card View** / **List View**), **Select Multiple**, and **Per page** when space is tight.

Scope tabs (when shown): **All**, **Mine**, **Shared with me**, **Shared by me**. Active filters appear as chips; use **Clear all** to reset.

## Bookmark URL parameters

The bookmarks page reads optional query parameters from the address bar. **Sort order** is controlled on the page (not via the URL).

| Parameter | Meaning |
|-----------|---------|
| `folder_id` | Filter to a single folder (folder UUID). |
| `tag_id` | Filter to a single tag (tag UUID). |
| `scope` | Library scope: `mine`, `shared_with_me`, `shared_by_me`, or `shared` (treated like `shared_with_me`). Invalid or missing values behave like **All**. |
| `pinned` | When `pinned=true`, only pinned bookmarks are listed. |
| `q` | Search text applied to the list (same idea as submitting the toolbar search). |
| `view` | Layout: `cards` or `table`. A valid value is also saved as the default view in the browser. |
| `limit` | Page size: **50**, **100**, **200**, or **500** (other values fall back to **50**). |
| `create` | If `create=true`, opens the create-bookmark flow once, then the parameter is removed from the URL. |
| `import` | If `import=true`, opens import once, then removed. |
| `export` | If `export=true`, runs export once, then removed. |
| `edit` | If set to a bookmark id, loads that bookmark into the editor once (shows an error if you cannot access it), then removed. |

**Scope tabs** in the UI (All / Mine / Shared with me / Shared by me) are shown when the app enables that scope UI. On Cloud, that requires the **Team** plan after plan info has loaded; otherwise the scope query parameter is cleared. Self-hosted uses the core app behavior where those tabs are available without that Cloud plan gate.

Pagination uses the **Previous** / **Next** controls on the page; the current page is **not** stored in the URL.

## Bulk actions

Choose **Select Multiple** from **More**, select rows, then use the bottom bar for **Move to Folder**, **Add Tags**, **Share with Teams** (when sharing is available), **Delete Selected**, **Select All**, **Deselect All**, or selecting all matching the current filters when offered.

## Command palette

The command palette is the dialog opened by **Ctrl+K** (**⌘K** on Mac) from anywhere in the app, or by selecting the large command bar on the **Overview** dashboard (accessible name **Open command palette**). Its input uses the same placeholder as the dashboard: **Type a command or search bookmarks**.

### When the input is empty

Results are grouped as:

- **Navigation** — **Bookmarks**, **Folders**, **Tags**, and **Admin** if your account can access workspace admin.
- **Quick Actions** — **Create Bookmark**, **Create Folder**, **Import**, **Export** (these navigate or open the right flow on **Bookmarks**).

### When you type a normal search

The app searches bookmarks (and matches navigation and quick-action labels). Choosing a bookmark opens its URL in a new tab; choosing a folder or tag sends you to **Bookmarks** with the corresponding filter.

### Go mode (`go …`)

If the query matches the `go` command pattern (for example `go` alone or `go myslug`), the list switches to a **Go** group: bookmarks whose **Slug** matches are shown, with `go/<slug>` shown under each title. Choosing an item opens that bookmark’s URL.

Press **Enter** when the line looks like `go <slug>` (or a pasted `/go/<slug>` path) to open the forwarding URL for that slug in a new tab.

<Callout kind="tip">
  For setting up your browser’s address bar to use the same `go` idiom, use the in-app **Search engine guide** (`/search-engine-guide`) linked from bookmark UI copy where shown.
</Callout>
