## What this is for

Self-hosted SlugBase lets you **Import** bookmark files and **Export** your library as JSON from **Bookmarks**. Use imports to migrate from another tool or a browser export; use export for backups and moving data between instances you control.

<Callout kind="info">
  This page documents **self-hosted** behavior from the core app. Hosted plans may enforce bookmark limits on import; see the Cloud product docs starting at [Cloud introduction](/cloud/introduction) if you use slugbase.app.
</Callout>

## Before you start

Open **Bookmarks** (`/bookmarks`). Import and export live in the toolbar **More** menu (**More**) as **Import** and **Export**.

You can also open **Import** via **Quick Actions** in the command palette (**Ctrl+K** / **⌘K**), or from dashboard checklist links such as **Import browser bookmarks** when that banner is visible.

## Import

<Steps>
  <Step title="Open Import" icon="upload" titleType="p">
    On **Bookmarks**, open **More**, then **Import** (dialog title **Import**).
  </Step>
  <Step title="Choose a file" icon="file" titleType="p">
    Select **Select File** and pick a `.json` or `.html` file (accepted types are restricted to those extensions).
  </Step>
  <Step title="Confirm results" icon="check" titleType="p">
    The app shows a toast summarizing success and failures, for example **Imported {{success}} bookmark(s), {{failed}} failed** (wording comes from the UI strings). Close the dialog with **Cancel** if you only dismiss without another file.
  </Step>
</Steps>

### Supported formats (in-app copy)

The dialog explains:

- **Import bookmarks from a JSON or HTML file. JSON files should contain an array of bookmark objects with title and url fields.**
- **Supported formats: JSON, HTML (Netscape bookmark format)**

Implementation details you should know:

- **JSON** — may be a top-level array of objects, an object with a `bookmarks` array, or a single bookmark object; entries need usable `title` and `url` fields.
- **HTML** — Netscape-style bookmark exports; very large files (over 10MB) are rejected by the client with an error message.

<Callout kind="alert">
  Only import files you trust. The app validates URLs to block dangerous schemes (such as `javascript:`) during HTML parsing.
</Callout>

## Export

<Steps>
  <Step title="Open Export" icon="download" titleType="p">
    On **Bookmarks**, open **More**, then **Export**.
  </Step>
  <Step title="Save the file" icon="save" titleType="p">
    The browser downloads a JSON file named like `slugbase-bookmarks-YYYY-MM-DD.json` containing your exported bookmarks.
  </Step>
</Steps>

The live **Export** action downloads **JSON** only. The in-app locale also defines **Export as JSON** and **Export as HTML** strings, but the current toolbar **Export** control triggers the JSON download path. For HTML interchange, use **Import** with an HTML file from another source, or convert exports yourself if you need a different format.

<Callout kind="tip">
  **Export** from **Quick Actions** in the command palette runs the same flow—it navigates to **Bookmarks** with export triggered.
</Callout>
